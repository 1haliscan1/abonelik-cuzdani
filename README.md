# Abonelik Cüzdanı

Aboneliklerini tek yerde takip eden, zamdan ve çekimden önce uyaran, uygun kart kampanyasını gösteren telefona kurulabilir web uygulaması (PWA).

- `index.html`: uygulamanın tamamı
- `campaigns.json`: kampanya ve fiyat verisi, her gün güncellenir
- `manifest.webmanifest`, `sw.js`, `icons/`: ana ekrana kurulum ve çevrimdışı çalışma

Bu dal (`gh-pages`) GitHub Pages ile yayınlanır.
